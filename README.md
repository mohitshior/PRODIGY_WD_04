# Personal Portfolio Website — Prodigy Infotech Task-04

Responsive personal portfolio website created with HTML, CSS and JavaScript.

## Included sections
- Home / Hero
- About Me
- Education and focus
- Skills
- Projects
- Professional / internship experience
- Contact section
- Responsive mobile navigation

## Run in VS Code
1. Extract the ZIP.
2. Open the `Personal-Portfolio` folder in VS Code.
3. Open `index.html`.
4. Run with Live Server, or open `index.html` directly in your browser.

## Main files
- `index.html` — website content and structure
- `style.css` — complete responsive styling
- `script.js` — mobile menu interaction

## Important
The profile image area currently uses a clean initials design (`MG`) so the project works without any external image file. You can replace it later with your own professional photo if required.
